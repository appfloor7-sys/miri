## 미리보기 (작업환경별)

### A. 화면만 빠르게 보기 — `preview/all-screens.png`
10개 화면이 한 장에 들어 있습니다. 패널에서 이미지는 그대로 렌더링됩니다.
개별 캡처는 `preview/1-onboarding.png` ~ `preview/10-settings.png`.

> ⚠️ **Files 탭의 `리치/일반` 뷰는 텍스트 뷰어입니다.** HTML을 실행하지 않으므로
> `standalone.html`을 거기서 열면 흰 화면이 나옵니다(정상). 앱을 실제로 조작하려면
> B/C/D 중 하나를 쓰세요.
> (JS가 막힌 환경에서도 흰 화면이 아니라 온보딩 정적 내용이 보이도록 처리는 해뒀습니다.)

### B. 내 PC에서 — NAS 공유 폴더
이 저장소는 NAS 볼륨(`/appfloor`)이라 탐색기/파인더에서 바로 열립니다.

```
\\<NAS>\appfloor\miri\standalone.html     # Windows
smb://<NAS>/appfloor/miri/standalone.html  # macOS
```

`file://`이라 **설치·오프라인·알림은 안 되고**, UI/타이머/기록은 전부 동작합니다.

### C. 폰에서 — 카톡/에어드롭
`standalone.html` 하나만 보내면 됩니다. 아이 관찰 테스트는 반드시 실제 폰/태블릿으로 하세요.

### D. 제대로 — HTTPS에 올려 PWA로
설치·오프라인·알림이 필요하면 HTTPS여야 합니다.

- **Synology Web Station**: `miri/`를 NAS `web/` 폴더로 복사 → `https://<NAS>/miri/`
- **정적 호스팅**: `npx vercel --prod` 또는 `netlify deploy --prod --dir=.`

> ⚠️ `python3 -m http.server`로 띄운 `127.0.0.1:8099`는 **샌드박스 컨테이너 안에서만**
> 유효합니다. 호스트나 폰에서 열리지 않습니다.

## 배포

정적 파일이라 아무 데나 올리면 됩니다. HTTPS면 폰 브라우저에서 열고
**홈 화면에 추가** → 앱처럼 실행됩니다.

## 단일 파일 재생성

소스를 고친 뒤 `standalone.html`을 갱신:

```bash
python3 make-standalone.py
```

## 구조

```
miri/
├─ index.html            # 모든 화면 (온보딩/홈/카드/기록/설정/아이 화면)
├─ css/app.css           # 디자인 토큰 + 화면별 스타일
├─ js/store.js           # 상태·기록·통계 (localStorage, 서버 없음)
├─ js/app.js             # 라우팅·타이머 엔진·이벤트
├─ standalone.html       # 전부 인라인된 단일 파일 (미리보기/전송용)
├─ make-standalone.py    # standalone.html 재생성
├─ manifest.webmanifest  # PWA 설치 정보
├─ sw.js                 # 오프라인 캐시
└─ icons/                # 192/512 PNG + SVG
```

빌드 도구 없음. 의존성 없음. 파일 고치면 새로고침이 끝.

## 구현된 것

| 기능 | 상태 | 비고 |
|---|---|---|
| 온보딩 3단계 | ✅ | 나이 → 힘든 순간 → **즉시 3분 실행** |
| 예고 시계 | ✅ | 모래가 줄고 토끼가 내려옴. 글자·숫자 0개 |
| 30초 예고 | ✅ | 토끼 손흔들기 + 소리 + 진동 |
| 종료 → 화면 소멸 | ✅ | 토끼가 문으로 들어가고 화면이 사라짐. "더 보기" 없음 |
| 둘 중에 골라 | ✅ | 4세트 × 4장 풀에서 매번 2장 랜덤, 선택 기록 |
| 전환 기록 | ✅ | 성공/연장/중단, 오늘 타임라인, 7일 차트 |
| 프리셋 편집 | ✅ | 시간(HH:MM) + 기본 분(5/10/15/20) |
| 소리 | ✅ | WebAudio. 오디오 파일 없음 |
| 알림 | ⚠️ | 앱이 열려 있을 때만. 서버 푸시는 2차 |
| PWA 오프라인 | ✅ | Service Worker 캐시 우선 |
| 데이터 | ✅ | localStorage, 기기 밖으로 안 나감 |

## 의도적으로 안 만든 것

- **아이 감정 기록** — 감시 도구가 되는 순간 아이가 입을 닫습니다
- **부모 점수·등급·순위** — 자책은 행동을 막습니다
- **아이 학습 콘텐츠** — 미션과 무관하고 경쟁이 과열된 시장
- **회원가입** — 첫날에 아무것도 요구하지 않습니다

## 아이 화면 규칙 (깨지 말 것)

1. **글자 0개.** 5세가 읽을 수 있는 건 그림과 색뿐
2. **끝나면 즉시 사라짐.** "더 보기" 버튼 금지
3. **나가려면 1.5초 길게 누르기** (부모용, 아이가 우연히 못 누름)
4. 종료 후 뜨는 두 버튼은 **부모용**이며 16초 뒤 자동으로 닫힘

## 타이머 정확도

`endsAt = Date.now() + 분*60000`을 저장하고 매 tick마다 남은 시간을 **다시 계산**합니다.
`setInterval` 누적 오차나 백그라운드 스로틀링에도 시간이 흘러가지 않습니다.
앱을 백그라운드에 두었다 돌아오면 `visibilitychange`에서 즉시 재계산합니다.

## 테스트

Playwright 스모크 테스트로 확인한 경로:

- 온보딩 3단계 → 3분 실행 → 길게 눌러 중단 → 홈 복귀
- 타이머 종료 → 종료 패널 → `연장` 기록 전환 → 3분 재시작
- 카드 선택 → 기록 저장 → "한 번 더" → 닫기
- 새로고침 후 상태 유지
- 320 / 390 / 768px 가로 스크롤 없음, 콘솔 에러 없음

수동 확인 권장: **실제 아이에게 3분 시계를 보여주고 언제 화면에서 눈을 떼는지** 관찰.
그게 이 앱이 팔릴지 결정하는 유일한 데이터입니다.
